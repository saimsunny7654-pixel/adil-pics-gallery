ADIL PICS GALLERY — NEXT LEVEL
================================
This build is a premium responsive photo-gallery UI with:
- 100 curated photographic image entries
- Search by subject/title/category
- Category filters
- Favorites saved in browser localStorage
- Fullscreen preview
- Download action
- Responsive masonry-style gallery
- No random image generator or LoremFlickr/Picsum dependency

IMPORTANT:
The gallery uses photographic image URLs from Unsplash for the displayed assets.
If you want a fully offline ZIP with the actual JPG files physically inside /images,
those image files must be downloaded through a network-enabled environment and
their license/attribution requirements should be checked before redistribution.

GitHub Pages:
1. Upload all files to a repository.
2. Settings → Pages → Deploy from branch → main / root.
3. Open the generated GitHub Pages URL.
